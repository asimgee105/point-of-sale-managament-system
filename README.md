# CloudPOS — customized POS application

This is the supplied Laravel POS application with a blue/teal visual refresh and verified setup, login, authentication, validation and PDF fixes. It requires PHP 8.2 or newer, Composer, and MySQL/MariaDB.

Start with **docs/LOCAL_SETUP_URDU.md**. Review **docs/CHANGES_AND_TESTS.md** for the changes, test results and remaining issues. Compiled frontend assets are included; Node.js is needed only when changing React source.
